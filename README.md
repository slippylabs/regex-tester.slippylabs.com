# Regex Tester

Test a regular expression against sample text with live match highlighting. Runs entirely in your browser.

**Live:** <https://regex-tester.slippylabs.com/>

## What it does

- Test a regular expression against sample text with live match highlighting.
- Capture groups listed per match, with the usual flag toggles.

## Run it locally

A static site. No build step, no package manager, no dependencies:

```
git clone git@github.com:slippylabs/regex-tester.slippylabs.com.git
cd regex-tester.slippylabs.com
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
